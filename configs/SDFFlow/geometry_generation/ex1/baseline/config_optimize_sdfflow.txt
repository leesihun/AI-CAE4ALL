% geometry_generation/ex1 - sdfflow; the suite's only CLOSED-LOOP mode. It trains nothing:
%   it chains generate -> gmsh tet mesh -> linear-static structural solve -> CMA-ES over the
%   trained DeepJEB generator, so every candidate is NEW geometry from the flow-matching model,
%   scored by an actual FEA run rather than by a distance to the dataset.
% This route is DeepJEB-specific. The load cases, the bracket bounding-box length scale, and the
%   Ti-6Al-4V constants below describe the ex1 brackets; do not copy them to ex2/ex3/ex4.
% CMA-ES searches the FM NOISE, not the VAE latent: opt_subspace_dim coordinates tilt one base
%   noise draw toward as many Gaussian directions (the gnomonic chart), so every point it visits
%   is an exact N(0, I) noise and on-manifold for the generator. opt_condition_dims must be a subset
%   of the FM checkpoint's condition names -- volume, area here, matching condition_names in
%   config_train_sdfflow.txt.
% opt_latent_range is absent, so the box half-width is opt_shell_scale 1.25: the corner
%   (|x| = 4.33 at 12 coordinates) turns the noise 77 degrees from the base draw. Nothing is
%   clipped, so a wider box is a genuinely larger search, not a degenerate one.
% Units are SI throughout: opt_length_scale 0.10556 is metres per normalized unit (0.19 m / 1.8,
%   so the 1.8-unit long axis is a 190 mm bracket), opt_material_e 113.8 GPa and
%   opt_yield_stress 903 MPa are Ti-6Al-4V. A generated
%   shape lives in the unit cube; without the length scale the stresses are meaningless.
% opt_budget 120 CMA-ES evaluations at popsize 8 = 15 generations, plus opt_baseline_size 12
%   unoptimized samples to calibrate the allowables against the population.
% Requires gmsh, pyamg and cma in the SDFFlow venv (mode optimize only).
% Writes optimized/baseline/typical .stl, summary.json, history.json, report.md under output_dir.
% Reference: https://arxiv.org/abs/2410.23130 ; https://arxiv.org/abs/2301.11445 ; https://arxiv.org/abs/2210.02747
% No source HDF5 writes. Checkpoints are created by the paired training config.

% T512 COMPARISON ARM (configs only; baseline/ stays the default at 128 tokens). Same
%   recipe as ../baseline/config_train_sdfflow.txt except latent_tokens 512, the matching
%   time shift fm_time_logit_mean = -ln(sqrt(512/32)) = -1.386, and its own output
%   directory. The 2026-09 token-count study found 512 tokens need far more than 10^3
%   training shapes; this arm tests that on the rebuilt ex3 set for fine detail (slots,
%   threads). The VAE stage is ~4x the 128-token compute and memory.
% geometry_generation/ex3 - sdfflow on MCB (5-class nut subset; 1320 train / 330 infer, 8:2 split).
% Logical order: input -> output -> conditioner -> partNo (named HDF5 arrays, not nodal rows).
% Train input: surface_points, surface_normals, query_xyz; generation input: latent noise and query_xyz.
% Output: signed_distance (zero level set is the generated surface).
% Dataset rebuilt 2026-10-01 (build_dataset.py): a MeshFix result is replaced by the
%   generalized-winding-number remesh (--repair_fallback winding, --winding_resolution 192) when
%   it is not watertight, when < 80% of the source surface lies on it (--min_area_retention 0.8),
%   or when > 5% of its own surface lies on no source face (--max_added_area 0.05: MeshFix caps
%   a bore it cannot stitch, and a total-area ratio passes the cap) -- before this, 21% of the
%   training labels (86% of castle nuts) were MeshFix fragments blown up to the unit box. Every part is
%   also rotated so its principal inertia axes are the coordinate axes, hole axis on z
%   (--canonicalize inertia); the old set had hole axes z 750 / x 372 / y 183.
% Conditioner order: bbox_x, bbox_y, bbox_z, volume, area, the five class_* one-hots
%   (add_mcb_class_conditions.py), hole_count (the genus of the processed mesh). The geometric
%   five alone cannot tell a castle nut from a hexagonal one, so the class one-hots and the hole
%   count are selected for FM conditioning here.
% cond_dropout_mode per_dim: each entry is dropped independently, so a request may give the class
%   only and leave the dimensions 'nan' (unspecified).
% condition_clip 10 (was 5): a one-hot of a class with share p normalizes to sqrt((1-p)/p) sigma,
%   which a 5-sigma clip would cut for any class under 4%.
% vae/fm_num_test_shapes 8 and mc_resolution_test 128 (were 2 and 64): the periodic picture is
%   shaded, seeded, and draws every body (minor bodies red); 64^3 hid the nut holes.
% split_by_parent False: MCB parts have no lineage attr (unlike DeepJEB).
% Reference: https://doi.org/10.1007/978-3-030-58523-5_11 ; https://arxiv.org/abs/2301.11445 ; https://arxiv.org/abs/2210.02747
% No source HDF5 writes. Checkpoints are created by this config; the paired infer config reads them.

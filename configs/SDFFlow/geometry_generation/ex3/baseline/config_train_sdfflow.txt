% geometry_generation/ex3 - sdfflow on MCB (5-class nut subset; 1305 train / 329 infer, 8:2 split).
% Logical order: input -> output -> conditioner -> partNo (named HDF5 arrays, not nodal rows).
% Train input: surface_points, surface_normals, query_xyz; generation input: latent noise and query_xyz.
% Output: signed_distance (zero level set is the generated surface).
% Conditioner order: bbox_x, bbox_y, bbox_z, volume, area. partNo: absent.
% All five geometric descriptors ARE selected here, unlike ex2: every one varies strongly on MCB
%   (std 0.33..2.57, ~3.0 effective degrees of freedom) because different nut classes put their
%   longest axis on different axes, so the 1.8 normalization does not pin any single one.
% The five class_* one-hots written by add_mcb_class_conditions.py stay in the cond_extra sidecar
%   for stratification and evaluation only -- they are NOT selected for FM conditioning, per
%   methods/SDFFlow/CLAUDE.md. Add them to condition_names to train a class-conditional model.
% split_by_parent False: MCB parts have no lineage attr (unlike DeepJEB).
% Reference: https://doi.org/10.1007/978-3-030-58523-5_11 ; https://arxiv.org/abs/2301.11445 ; https://arxiv.org/abs/2210.02747
% No source HDF5 writes. Checkpoints are created by this config; the paired infer config reads them.

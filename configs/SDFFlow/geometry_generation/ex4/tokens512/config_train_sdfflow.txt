% T512 COMPARISON ARM (configs only; baseline/ stays the default at 128 tokens). Same
%   recipe as ../baseline/config_train_sdfflow.txt except latent_tokens 512, the matching
%   time shift fm_time_logit_mean = -ln(sqrt(512/32)) = -1.386, and its own output
%   directory. The 2026-09 token-count study found 512 tokens need far more than 10^3
%   training shapes; this arm tests that on the rebuilt ex4 set for fine detail (slots,
%   threads). The VAE stage is ~4x the 128-token compute and memory.
% geometry_generation/ex4 - sdfflow on Thingi10K (3441 train / 860 infer meshes, split by Thing).
% Logical order: input -> output -> conditioner -> partNo (named HDF5 arrays, not nodal rows).
% Train input: surface_points, surface_normals, query_xyz; generation input: latent noise and query_xyz.
% Output: signed_distance (zero level set is the generated surface).
% Dataset rebuilt 2026-10-01 from the official Thingi10K metadata: solid, single-component,
%   manifold and closed meshes only (4,301 files / 1,067 Things; make_thingi_lists.py), with
%   the Thing ID written as each shape's 'group' attr (--split_groups). The train/infer split
%   is drawn by Thing (819 / 248 Things), so no Thing has files on both sides; before this, 92%
%   of the held-out shapes shared a Thing with a training shape.
% Conditioner order: bbox_x, bbox_y, bbox_z, volume, area, then the 11 cat_* one-hots of the
%   Thingi10K Category field (add_thingi_category_conditions.py; cat_none = no category, 16%).
%   Thingi10K is a grab bag with no shared parameterization; the category is the only semantic
%   label it carries, so it is what this route conditions on.
% cond_dropout_mode per_dim: each entry is dropped independently, so a request may give the
%   category only and leave the dimensions 'nan' (unspecified).
% condition_clip 10 (was 5): the rarest category (cat_3d_printing, 1.6%) normalizes to 7.8 sigma.
% split_by_parent True: the split reads the 'group' attr, i.e. it is drawn by Thing ID.
% Warmup schedules are scaled to the shorter run (400 vs ex1's 1500 VAE epochs) so KL annealing
%   still finishes in the first ~14% of training rather than halfway through it.
% vae/fm_num_test_shapes 8 and mc_resolution_test 128 (were 2 and 64): the periodic picture is
%   shaded, seeded, and draws every body (minor bodies red).
% Reference: https://arxiv.org/abs/1605.04797 ; https://arxiv.org/abs/2301.11445 ; https://arxiv.org/abs/2210.02747
% No source HDF5 writes. Checkpoints are created by this config; the paired infer config reads them.

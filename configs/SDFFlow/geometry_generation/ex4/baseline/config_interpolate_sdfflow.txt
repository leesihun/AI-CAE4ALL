% geometry_generation/ex4 - sdfflow; CONDITIONAL INTERPOLATION between two generated objects,
%   from the checkpoints trained by the paired config_train_sdfflow.txt. Like mode sample this
%   produces NEW geometry -- it never opens the dataset; both endpoints are drawn from noise.
% interpolation_space slerp_noise: the two endpoints are FM noise rows, spherically
%   interpolated and then integrated through the ODE, so every intermediate is a real sample of
%   the generator rather than a latent-space blend the decoder was never trained on. lerp_latent
%   (a straight line in latent space) is not used: on MCB half of its midpoints fell outside the
%   training distribution.
% cond_values: ONE request shared by every row of the strip (16 entries in checkpoint order:
%   bbox_x, bbox_y, bbox_z, volume, area, cat_3d_printing, cat_art, cat_fashion, cat_gadgets, cat_hobby, cat_household, cat_learning, cat_models, cat_tools, cat_toys_and_games, cat_none). Only the one-hot entries are given; the rest are 'nan'
%   (unspecified, allowed because the checkpoint is cond_dropout_mode per_dim). Both endpoints
%   are therefore the same object class, and the strip morphs within it.
% seed 42 + source_num_samples 16 draw the SAME noise batch as config_infer_sdfflow.txt would
%   with these cond_values and num_samples 16, so endpoint i is that run's sample i.
% interpolation_steps 7: alphas linspace(0, 1, 7), both endpoints included, so a sudden flip
%   (an orientation change, a hole opening) shows where it happens instead of hiding between
%   alpha 0 and 0.5. alpha is not read when interpolation_steps is set.
% max_condition_z 10: a rare class one-hot normalizes up to condition_clip (10) sigma.
% Writes .stl per panel plus one strip PNG under output_dir.
% Reference: https://arxiv.org/abs/1605.04797 ; https://arxiv.org/abs/2301.11445 ; https://arxiv.org/abs/2210.02747
% No source HDF5 writes. Checkpoints are created by the paired training config.

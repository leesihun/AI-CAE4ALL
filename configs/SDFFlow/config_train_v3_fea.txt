%
%       python add_fea_conditions.py --h5 ../../dataset/deepjeb.h5 \

%       python add_fea_conditions.py --h5 ../../dataset/deepjeb.h5 \

%   The join is basename(source) == item_name (2138/2138 match); the builder writes all
%   registry names in STORED space (natural log for the log_* names), and the dataset
%   then reports cond_names = the five geometric descriptors + the FEA names, from

%   so ex1/ex2/ex4 configs are unaffected. Known data defect: shape h5 index 2099

%   labels (mass 1.07 kg, volume*scale^3 off by +429%); its labels do not describe its

%   Everything except the conditioning block is config_train_v3.txt verbatim (ex4/),
%   so ex4 vs ex5 isolates the condition set. Departures, and why:
%     - condition_names volume,area + log_max_ver_stress_mpa, log_max_dia_stress_mpa,
%       log_max_tor_stress_mpa, log_first_mode_freq_hz. The label analysis (263 parents,
%       parent-grouped CV) picked the decorrelated set: volume/area are the two
%       geometric DOF and the only proxy-guidable ones; vertical stress is the primary
%       GE load case and stands in for vertical displacement (r 0.91) and most of the
%       horizontal case (R^2 0.70/0.92); diagonal stress is design_loop's second default
%       case and only 29% predictable from geometry; torsion stress is the one label
%       orthogonal to everything else (R^2 -0.04 from geometry, unique info 0.91) --
%       and the riskiest (ICC 0.06); the 1st mode is the modal DOF (r 0.95 with the 2nd).
%       Participation ratio 2.53 and 4 PCs for 90% variance versus 1.43 for v3's
%       volume,area. Left out as duplicates: mass_kg and volume_mm3 (= 4.793 x volume,
%       constant density), surface_area_mm2 (= 10468 x area), the displacements
%       (0.58-0.85 predictable from geometry, r 0.91 with their stress), horizontal
%       stress/displacement (recovered from the vertical case), the 2nd mode.
%     - cond_dropout_mode per_dim: an independent Bernoulli mask per condition entry with
%       a learned null value and the mask fed to the network, so a sample request can
%       leave entries 'nan' (a designer specifies mass and one stress, not six numbers)
%       and cond_sweep can morph one axis. 'all' would keep the legacy single mask.
%     - cond_dropout 0.2 (v3: 0.1): the mask distribution has to contain the request
%       patterns inference will use. At 0.2 a given two-of-six-unspecified pattern is
%       1.6% of rows (~28k examples over ~27k updates x 64), 74% of entries stay
%       observed, and the all-masked row is 6e-5 -- fine while cfg_scale stays 1.0 (the
%       unconditional branch is then never used), but a CFG curve re-measured on this
%       checkpoint would read a starved branch; add an explicit drop-all term first.
%     - max_condition_z at inference must be >= 4 for the test split: the test targets
%       reach |z| 3.82 (area), 3.21 (torsion stress), 3.06 (volume), 3.02 (2nd mode).

%   Conditional benchmark on the ex5 TEST split (config_train_v3_fea.txt). For eval_num_shapes
%   seeded-random test shapes the target is that shape's TRUE stored condition vector
%   (restricted to the checkpoint's six cond_names), and every method in eval_methods
%   starts from the SAME base noise per shape (paired z0 seeded by eval_seed and the shape
%   index), so method differences are not noise differences:
%     plain      -- one conditional sample per shape (50 NFE)
%     rejection  -- best-of-candidate_multiplier by geometric condition error (the shipped
%                   sample-mode mechanism; 4 x 50 NFE)
%     e2         -- plain + newton_rounds of proxy-Jacobian Newton correction on the true
%                   Marching Cubes volume/area (needs descriptor_calibration_path)
%     c2 / c2e2  -- add them to eval_methods, with guidance_t_start 0.3 / guidance_eta 0.1 /
%                   guidance_step_mode velocity_dt, once the ex5 calibration exists
%   Per method and per condition name it reports the relative error |actual - target| /
%   |target| in RAW units (MPa / Hz via from_stored, normalized volume / area) as median
%   and p95, the valid/watertight rate, the latent RMS drift from the plain sample, the
%   NFE count and wall time, to eval_conditional.json/.csv plus a printed table.
%   The four FEA-named conditions are 'not measurable geometrically' under
%   condition_audit geometric; fea / surrogate re-measure them with design_loop
%   (relative-only: tet4 is stiff and the solver reports a stress percentile).
%   Protocol facts to keep in mind when reading the numbers:
%     - calibration on val (config_calibrate_descriptors.txt), scoring on test; touch test once.
%     - the parent-grouped split is IN-distribution in condition space (test nearest-train
%       distance ratio ~1.0, <= 0.5% of test values outside the train range): this measures
%       whether seen condition values can be realised with unseen bracket families, not
%       condition extrapolation. Extrapolation targets must be constructed explicitly.
%     - test targets reach |z| 3.82 (area) and 3.21 (torsion stress) under train statistics,
%       so max_condition_z must be >= 4 or those shapes are rejected before sampling.
%     - shape h5 index 2099 (source 131_561) is a partial STL with full-bracket labels; it
%       is dropped by the eval_exclude_shapes line below, not by prose.
%     - c2/e2/c2e2 optimise volume and area ONLY (the soft SDF proxy has no stress form),
%       while the table scores whatever condition_audit can measure. On DeepJEB
%       corr(volume, log_max_ver_stress) = -0.76 and corr(volume, log_first_mode) = +0.82,
%       so a volume-driven latent step necessarily moves the FEA conditions too. The run
%       prints a SCOPE line naming what each method optimises versus what is scored.
%     - the printed table carries a per-condition n and a PAIRED block (only the shapes
%       every method could be measured on). Compare methods on the paired block: an
%       unpaired median is taken over a method-selected subsample, and a method that
%       breaks the meshes it cannot correct looks better for it.

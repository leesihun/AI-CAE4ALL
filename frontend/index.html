Welcome to AI-CAE4All Studio

Three things worth knowing before you build your first pipeline.
  1. Build left to right on the canvas Drag a block out of the library on the left, then drag between the coloured sockets to connect them. Data flows from a source, through a model, into an evaluation or export block.
  2. Click a block to configure it The inspector on the right holds the common settings. Open full configuration shows every key the real launcher accepts, with the flat .txt config kept in sync beside it.
  3. Validate before you run Validate runs the same preflight the command line does and reports every problem at once. Run pipeline then launches the native process, and its live output appears in the runtime panel.

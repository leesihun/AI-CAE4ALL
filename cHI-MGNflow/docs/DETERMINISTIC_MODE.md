# 결정론 예측 — 문헌의 방법과 이 리포의 구현

> 확률 모델에서 결정론 예측을 얻는 방법은 하나가 아니다. 이 문서는 이미지 생성
> 문헌이 쓰는 방법들을 정리하고, 그중 이 문제에 맞는 것을 왜 골랐는지 적는다.

---

## 0. 두 가지 다른 목표를 먼저 구분한다

| 원하는 것 | 문헌의 방법 | 결과물 |
|---|---|---|
| **1-step 샘플링** (빠른 생성) | **Distillation** — progressive distillation, consistency models, rectified flow/ReFlow, DMD | 1-step **샘플러**. 여전히 확률적 |
| **조건부 평균** (결정론 예측) | **x₀-parameterization** (data prediction) | 결정론 예측기 |

**둘은 다르다.** 1-step 샘플러는 여전히 매번 다른 답을 낸다 — 그냥 빨리 낼 뿐이다.
HI-MGN과 비교하려면 후자가 필요하다.

이 리포가 구현한 것은 **후자**다.

---

## 1. Distillation 계열 (이 리포에 미구현)

| 방법 | 아이디어 | 왜 여기서 안 쓰나 |
|---|---|---|
| **Progressive distillation** | 학생이 교사의 2스텝을 1스텝으로 흉내내고, 재귀적으로 반복 | 학습 라운드가 여러 번 필요. 여전히 샘플러 |
| **Consistency models** | `f(y_t, t) = f(y_t', t')`를 궤적 위에서 강제 → 어느 지점에서든 1스텝에 끝점으로 | 별도 학습 단계. 여전히 샘플러 |
| **Rectified flow / ReFlow** | 학습된 모델로 (노이즈, 샘플) 쌍을 만들고 그 직선 쌍으로 재학습 → 경로가 곧아져 1스텝 가능 | 재학습 라운드 필요. 여전히 샘플러 |
| **DMD** | 분포 매칭으로 1-step 생성기를 증류 | 위와 동일 |

**공통점**: 전부 **추가 학습 단계**를 요구하고, 산출물은 **샘플러**다.
추론 속도가 병목이 되면(§7의 `flow_steps` 튜닝으로 부족할 때) 그때 도입할 후보다.

## 2. 이 리포가 쓰는 방법 — x₀-parameterization

Diffusion 모델은 같은 대상을 세 가지로 매개변수화할 수 있다:

| 이름 | 네트워크가 예측하는 것 |
|---|---|
| ε-prediction | 노이즈 |
| **x₀-prediction** (data prediction) | **깨끗한 데이터** |
| v-prediction | 속도 |

셋은 선형 변환으로 서로 연결되지만 **loss 가중치가 달라지고**, 따라서 네트워크가
무엇을 잘하게 되는지가 달라진다.

**x₀-prediction의 출력은 정의상 `E[x₀ | x_t, t, g]`다.** `t=0`에서 이것은 곧
`E[y | g]` — **추가 산술 없이 조건부 평균 그 자체**다.

### 이 리포에서의 정확한 관계

경로가 `y_t = (1−s·t)·z₀ + t·y₁`, 속도 목표가 `u = y₁ − s·z₀` 이므로 (`s = 1 − σ_min`):

```
y₁ = s·y_t + (1 − s·t)·u                    (정확한 대수, model/flow.py::predict_x0)
```

따라서

```
‖x̂₀ − y₁‖²  =  (1 − s·t)² · ‖v̂ − u‖²
```

`s·y_t`는 입력이 주어지면 상수이기 때문이다.

> **즉 x₀-prediction은 속도 회귀에 `(1 − s·t)²` 가중치를 건 것과 정확히 같은 목적함수다.**

### 그래서 loss 가중치로 구현했다

네트워크는 **항상 속도를 출력**한다. 그러면:

- ODE 적분이 정확하게 유지된다 (변환 없음)
- 명시적 x₀ 헤드가 필요로 하는 `1/(1 − s·t)` 나눗셈이 없다 —
  그건 `t → 1`에서 `1/σ_min = 10⁴`로 발산한다

`flow_loss_weighting x0`은 수학적으로 x₀-prediction이면서 수치적 위험이 없다.

| `flow_loss_weighting` | 가중치 | 의미 |
|---|---|---|
| `uniform` | 1 | v-prediction. **샘플링에 최적** — ODE가 실제로 정확도를 필요로 하는 곳에 예산을 쓴다 |
| `x0` | `(1 − s·t)²` | data prediction. `t=0`에서 1, `t=1`에서 `σ_min² ≈ 10⁻⁸`. **결정론 끝에 예산 집중** |

가중치는 배치 내에서 합이 1이 되도록 정규화한다 — 그래야 파라미터화를 바꿔도
loss 스케일과 쓸 수 있는 learning rate가 움직이지 않는다.

## 3. `flow_det_prob` — 결정론 슬라이스에 예산을 명시적으로 준다

`t = 0`에서 경로 위 점은 노이즈 필드 그 자체이고, 그것은 `y`에 대한 정보를 하나도
담지 않는다. 그래서 그 슬라이스의 항은 (x₀ 가중치에서 `w(0) = 1`이므로):

```
‖ (z₀ + v̂) − y ‖²
```

**이것은 순수한 결정론 회귀다.** `E[y|g]`를 목표로 하는, 노이즈가 입력에 섞인 MSE.

`flow_det_prob p`는 그래프의 `p` 비율을 `t=0`에 고정한다. 즉 **같은 목적함수 안에서
결정론 모드에 명시적인 학습 예산 지분을 준다.** 읽어내는 게 아니라 학습시킨다.

```
flow_det_prob 0.0   결정론 모드는 t~0 근방에서 우연히 얻어지는 것
flow_det_prob 0.25  학습의 1/4이 결정론 회귀
```

## 4. 알려진 상충 관계

| 조합 | 결과 |
|---|---|
| `x0` + `flow_t_sampling logitnormal` | **상쇄된다.** logit-normal은 양 끝을 모두 덜 뽑는데, x₀ 가중치는 `t=0`에 몰아준다. 런처가 `FLOW-WEIGHT-CONFLICT` 경고 |
| `x0` 단독 | 조건부 평균 ↑, **`t≈1` 디테일 ↓**. 개별 샘플이 흐려진다 — 샘플을 날카롭게 만드는 게 바로 그 구간이다 |
| `uniform` 단독 | 샘플 품질 ↑, 결정론 모드는 부산물 |

**공짜 점심이 없다.** 하나의 체크포인트가 두 가지를 다 최고로 할 수는 없고,
`flow_loss_weighting` × `flow_det_prob`가 그 지점을 고르는 손잡이다.

## 6. 체크포인트 선택 — `best_by`

| 값 | 선택 지표 |
|---|---|
| `recon` | 1스텝 속도 회귀 loss (홀드아웃) |
| `crps` | 샘플링 앙상블 점수 — **추론이 하는 일과 같은 것** |
| `det` | 1-forward 결정론 readout의 MSE |

**`crps`와 `det`는 서로 어긋날 수 있다.** 체크포인트가 분포를 더 잘 덮게 되는 동안
조건부 평균은 표류할 수 있다. 제품이 앙상블이면 `crps`, 단일 예측이면 `det`.

학습 중 `[FlowDiag]` 줄에 셋 다 찍힌다:

```
[FlowDiag] crps=8.7e-02  det(1fwd) mse=1.9e-01  1-draw mse=2.4e-01  spread/gt=0.31
```

## 7. 실험 설계 (ex9)

`configs/cHI-MGNflow/ex9/` 세 arm. 백본·데이터·예산 동일, 목적함수만 다름.

| arm | 목적함수 | best_by | 무엇을 답하는가 |
|---|---|---|---|
| `det` | 결정론 MSE (HI-MGN) | recon | **정확도 기준선** |
| `fm_v` | flow, `uniform` | crps | 샘플링 최적 파라미터화에서 결정론 readout은 얼마나 되나 |
| `fm_x0` | flow, `x0` + `det_prob 0.25` | det | **결정론을 위해 학습하면 기준선을 따라잡나** |

ex9를 고른 이유: 900 샘플 × 20 timestep × 3131 노드 — 작은 메쉬에 많은 샘플이라
**충분한 epoch을 실제로 돌릴 수 있고**, `T=20`이라 `input_var` state 블록이
살아 있어 정적/동적 양쪽 경로가 동시에 검증된다.

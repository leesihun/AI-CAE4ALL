# 생성 모델 설계 — 제로베이스 재검토

> 2026-08-29. 기존 구조(HI-MGN-V), 기존 loss(recon/MMD/aux/fm), 기존 진단 결과를
> 전제하지 않고 처음부터 다시 세운 문서. GNN도 energy score도 전제하지 않는다.

---

## 0. 목표를 두 개로 분리한다

지금까지의 논의가 계속 미끄러진 이유는 **서로 다른 두 요구를 하나로 뭉쳐서** 말했기
때문이다. 먼저 분리한다.

### 요구 ① — 사실성 (realism)

> 생성된 **한 장의 필드**가 물리적으로 가능한 warpage 필드인가?

- 매끄러운가, 노드끼리 튀지 않는가
- 모드 형상이 실제 판재가 취할 수 있는 모양인가 (bowl / saddle / twist ...)
- 진폭이 물리적으로 말이 되는 범위인가

**한 장만 보고 판정 가능하다.** 사람이 눈으로 볼 수 있고, 고객에게 보여주는 것이 이것이다.

### 요구 ② — 보정 (calibration)

> 생성된 **샘플 뭉치의 분포**가 참 조건부 분포 `p(y|g)`와 같은가?

- 폭이 맞는가 (너무 좁지도 넓지도 않은가)
- 중심이 맞는가
- 꼬리(극단 사례)가 맞는가

**한 장으로는 절대 판정 불가.** 여러 형상에 걸친 통계로만 잰다.

### 둘은 독립된 축이다

```
                        보정 정확 ↑
                                  │
   ② OK / ① 실패                 │      ★ 목표
   노드별 독립 잡음               │      물리적 + 보정됨
   (모든 주변분포는 완벽,          │
    샘플은 공간적 백색잡음)        │
   ── GM-GNN 논문의 실패 ──       │
  ────────────────────────────────┼──────────────────────────→ 사실성 ①
                                  │
   ① 실패 / ② 실패                │   ① OK / ② 실패
   현재 상태                      │   결정론적 평균 예측기
   (envelope 밖 필드)             │   (항상 사실적, 폭이 0)
                                  │   mode-collapse GAN
```

**핵심:** 이 두 축을 동시에 올리는 것이 어렵다. 그런데 **①은 구조로 보장할 수 있고,
②는 loss로만 얻을 수 있다.** 이 비대칭이 아래 설계 결정의 전부다.

## 1. 이 문제의 정체 — 아직 측정되지 않은 단 하나의 사실

SAOI warpage는 **정적 탄성 문제의 해**다. 여기서 따라 나오는 성질:

1. **매끄럽다.** 타원형 PDE의 해라서 공간적으로 매우 매끄럽다.
   고주파 성분이 원리적으로 작다.
2. **저차 모드가 지배한다.** 판재 warpage는 업계에서조차 *bowl / saddle / twist*
   같은 **저차 형상 클래스**로 분류하고, 스칼라 하나(coplanarity = max−min)로
   보고한다. 이는 필드의 **내재 차원이 수십 이하**임을 강하게 시사한다.
3. 즉 `y ∈ R^(50,000 × 3)` 은 명목 차원이고, **실제 자유도는 그보다 3~4자리 작을
   가능성이 높다.**

**이것이 사실이면 설계가 완전히 달라진다.** 그리고 아직 측정된 적이 없다.

> 이 문서의 나머지 전부가 §3의 측정 결과에 달려 있다.

## 2. 두 갈래 설계

### 설계 A — 필드 공간에서 직접 생성

```
   z ~ N(0,I) ──┐
                ▼
   기하 g ──→ [ 네트워크 ] ──→ y_hat ∈ R^(N×3)
```

- 150,000차원 분포를 직접 모델링
- **사실성을 loss로 배워야 한다** (구조적 보장 없음)
- 밀도를 계산할 수 없으므로 **샘플 기반 점수(energy score)** 가 필요
- 확장성은 최고 (필드가 저차원이 아니어도 됨)

### 설계 B — 저차원 계수 공간에서 생성 + 결정론적 복원

```
   기하 g ──→ [ 결정론적 회귀 ] ──→ mu(g) ∈ R^(N×3)     ← 평균 필드 (전체 해상도)
        │
        └───→ [ 조건부 밀도 ] ──→ a ~ p(a|g),  a ∈ R^K   ← K ≈ 30~60
                                        │
                        y_hat = mu(g)  +  Phi(g) · a
                                          ↑ 매끄러운 기저 (다항식 등)
```

- 확률적인 부분만 **K차원**으로 축소
- **사실성이 구조적으로 보장된다**: 모든 샘플이 `mu + (매끄러운 기저의 선형결합)`
  이므로 정의상 매끄럽고 물리적
- `p(a|g)`가 K차원이라 **밀도를 명시적으로 쓸 수 있다** → **정확한 최대우도(MLE)**
  로 학습 가능. 샘플 기반 점수(ES)가 **필요 없다**
- 필드가 저차원이 아니면 기저 절단 오차가 커져서 실패

### 왜 설계 B가 목표에 더 잘 맞는가

§0의 2×2 그림으로 보면:

- **설계 A**는 원점(①실패/②실패)에서 시작해 **두 축을 동시에** 올려야 한다
- **설계 B**는 **①축의 오른쪽 끝에서 시작**해서 (기저가 사실성을 보장하므로)
  **②축 하나만** 올리면 된다

2차원 탐색이 1차원 탐색이 된다. 그리고 "사실적인 샘플도 중요하다"는 요구를
**희망이 아니라 보장**으로 만든다.

## 3. 결정 측정 — 설계를 고르는 단 하나의 실험

학습 없이, 반나절.

### 측정 3.1 — 필드가 저차원인가

각 샘플에 대해:

1. 좌표를 **정규 좌표계**로 옮긴다 — 중심 이동 + 좌표 PCA 축 정렬 + 스케일 정규화
   (Gladstone et al. 의 "simulation coordinates")
2. 정규 좌표의 다항식 기저 `Phi` (차수 D=2,3,4) 에 필드를 최소제곱 투영
3. `R² = 1 − ‖y − Phi·a‖² / ‖y − mean(y)‖²` 를 기록

| 결과 | 의미 |
|---|---|
| D=3에서 R² ≥ 0.95 (하위 10% 샘플도) | **설계 B.** 필드가 30개 숫자로 표현됨 |
| D=4에서도 R² < 0.8 | **설계 A.** 국소 구조가 실재함 |
| 중간 | 설계 C (§6) — 평균은 전 해상도, 잔차만 모달 |

### 측정 3.2 — 무엇을 생성해야 하는가 (조건부 스프레드)

`g`가 `y`를 결정해버리면 생성 모델 자체가 불필요하다.

1. 샘플별 특징 `phi(g)` = 조건 변수(두께, part no) + 기하 요약(bbox, 노드수, 좌표 PCA 계수)
2. 샘플별 응답 `psi(y)` = 위 다항식 계수 `a` (메쉬에 무관한 표현)
3. 각 test 샘플의 `phi` 공간 k=8 최근접 train 이웃을 찾아 그 `psi`들을 **의사 앙상블**로 사용
4. `psi` 공간에서 비교:

| 결과 | 의미 | 행동 |
|---|---|---|
| 1-NN(단일 점) ≈ k-NN 앙상블 | `p(y\|g)` 가 사실상 Dirac | **생성 모델 불필요.** 결정론적 회귀로 끝 |
| k-NN 앙상블 ≪ 전역 marginal | 기하가 설명력 있고 스프레드도 실재 | 생성 모델 필요. 이 k-NN 점수가 **모델이 이겨야 할 하한선** |
| k-NN 앙상블 ≈ 전역 marginal | 기하가 `y`를 설명 못 함 | 개별 정확도는 원리적으로 불가. 앙상블만 제품화 가능 |

### 측정 3.3 — 데이터 규모

`S` = 학습 샘플 수. `p(a|g)` 모델 복잡도를 이것이 결정한다.

| S | `p(a\|g)` 로 쓸 수 있는 것 |
|---|---|
| < 200 | 조건부 가우시안, 대각 공분산 |
| 200 ~ 1000 | 조건부 가우시안, **저계수+대각** 공분산 (모드 간 상관 포착) |
| 1000 ~ 5000 | 가우시안 혼합 (성분 5~20) — 다봉성(buckling) 대응 |
| > 5000 | 조건부 normalizing flow |

## 4. 설계 B의 loss — 항별 정확한 정의

### 표기

| 기호 | 의미 | 크기 |
|---|---|---|
| `g_s` | 샘플 s의 기하 (메쉬 + 조건 변수) | — |
| `y_s` | 정답 필드 | `[N_s, 3]` |
| `Xn_s` | 정규 좌표 (중심·PCA축·스케일 정규화) | `[N_s, 3]` |
| `Phi_s` | `Xn_s` 의 다항식 기저 (차수 D) | `[N_s, P]` |
| `a_s` | 계수 (채널별) | `[P, 3]` → 평탄화 `K = 3P` |
| `mu_θ` | 결정론적 필드 회귀기 | `g → [N,3]` |
| `h_ψ` | 기하 인코더 | `g → R^d` |
| `p_φ` | 조건부 밀도 | `R^K × R^d → R+` |

### 2단계 학습

#### 1단계 — 결정론적 평균 필드

```
L_mu  =  (1/S) Σ_s  (1/N_s) Σ_i Σ_f  w_f · ( mu_θ(g_s)_if − y_s,if )²
```

- 그냥 **가중 MSE**. 새로운 것 없음.
- 최소점 = 조건부 평균 `E[y|g]`
- 이것이 **사실성의 원천**: 회귀 출력은 매끄럽고 물리적이다
- 모노레포의 결정론적 `meshgraphnets` / `transolver` 를 그대로 써도 된다

#### 2단계 — 잔차의 조건부 밀도

잔차를 기저에 투영해서 계수를 얻는다 (학습이 아니라 **전처리**, 최소제곱 1회):

```
r_s    =  y_s − mu_θ(g_s)                         잔차 필드   [N_s, 3]
a_s    =  argmin_a ‖ Phi_s·a − r_s ‖²             계수        [K]
rho_s  =  ‖ r_s − Phi_s·a_s ‖ / ‖ r_s ‖           기저가 못 잡은 비율 ← 반드시 로깅
```

그리고 **정확한 최대우도**:

```
L_a  =  − (1/S) Σ_s  log p_φ( a_s | h_ψ(g_s) )
```

**이 한 줄이 전부다.** 항이 하나뿐이다.

### 각 항이 하는 일

| 항 | 무엇을 담당 | 최소점 | 왜 이것으로 충분한가 |
|---|---|---|---|
| `L_mu` | **사실성 ①** + 중심 정확도 | `E[y\|g]` | 회귀는 매끄러운 함수를 낸다. 별도 정칙화 불필요 |
| `L_a` | **보정 ②** | `p(a\|g)` = 참 조건부 분포 | log score 는 strictly proper. 밀도를 **직접 계산**하므로 추정량 분산이 없다 |

### 왜 여기서 energy score가 필요 없는가

energy score는 **밀도를 계산할 수 없을 때** 쓰는 우회로다. 150,000차원에서는
`log p(y|g)` 를 쓸 수 없으니 샘플 거리로 대체한다. 그 대가로:

- M개 샘플이 필요 (M배 연산)
- 추정량 분산
- 항이 몇 개 필요한지, 어느 스케일에서 재야 하는지 등 설계 자유도가 폭발

**K=30~60 차원에서는 `log p` 를 그냥 쓸 수 있다.** 우회로가 필요 없다.

### 샘플링 (추론)

```
h = h_ψ(g)
for m in 1..M:
    a^(m)     ~ p_φ( · | h )
    y_hat^(m) = mu_θ(g) + Phi(g) · a^(m)
```

`Phi(g)` 는 기하에서 해석적으로 계산 (학습 파라미터 없음). 샘플 M개 비용 =
회귀 1회 + K차원 샘플링 M회 ≈ **회귀 1회**. 현재 설계 대비 수십 배 빠르다.

### 검증 — 여기가 결정적으로 좋아진다

| 지표 | 계산법 | 현재 설계에서는 |
|---|---|---|
| **holdout NLL** | `−log p_φ(a_s\|h_s)` 를 test split에서 | **불가능** (밀도 없음) |
| 차원별 PIT/rank | `a` 의 각 차원마다 CDF 값의 균등성 | 통계력 부족 |
| 사실성 | `rho_s` (기저 절단 비율) — **학습 전에 이미 안다** | 학습 후에야 알 수 있음 |
| 조건부 커버리지 | `a` 공간에서 예측구간 포함률 | — |

**holdout NLL 하나로 모델 선택이 끝난다.** CRPS / wild-rate / rank histogram /
spread_ratio 를 조합해서 판단하던 것이 단일 숫자가 된다.

### 설계 B의 실패 조건 (정직하게)

1. `rho_s` 가 크다 (기저가 잔차를 못 잡는다) → 국소 구조가 실재. 설계 A로.
2. `p(a|g)` 가 다봉인데 가우시안을 썼다 → 혼합/flow 로 승급 (S가 허락하면)
3. 정규 좌표계가 형상마다 불안정 (PCA 축 부호/순서가 뒤바뀜) → 부호 규약을 고정해야 한다.
   외곽선이 극단적으로 다양하면 기저 자체를 재검토

## 5. 설계 A의 loss — 항별 정확한 정의

측정 3.1이 "저차원 아님"을 말할 때만 이 경로로 간다.

### 구조

```
   z ~ N(0,I)  ──┐
                 ▼
   기하 g ──→ [ 네트워크 f ] ──→ y_hat = f(g, z)
```

학습과 추론에서 z의 출처가 **동일**해야 한다. (현재 설계가 깨진 지점이 정확히 여기다:
학습은 `q(z|y)`, 추론은 `p(z|g)`.)

### 표기

`m, n = 1..M` 멤버, `i = 1..N` 노드, `f = 1..3` 채널, `w_f` 채널 가중치,
`eps = 1e-6` (평활화).

```
노드별 거리 (정답까지):    d_i^(m)  = sqrt( Σ_f w_f (y_hat_if^(m) − y_if)²        + eps² )
노드별 거리 (멤버 간):     e_i^(mn) = sqrt( Σ_f w_f (y_hat_if^(m) − y_hat_if^(n))² + eps² )

필드 전체 거리 (정답까지): D^(m)    = sqrt( (1/N) Σ_i Σ_f w_f (y_hat_if^(m) − y_if)²        + eps² )
필드 전체 거리 (멤버 간):  E^(mn)   = sqrt( (1/N) Σ_i Σ_f w_f (y_hat_if^(m) − y_hat_if^(n))² + eps² )

almost-fair 계수:          c(M,α)   = α/(M(M−1)) + (1−α)/M²
그래프 진폭 (detach):      s        = sqrt( (1/N) Σ_i Σ_f w_f y_if² ) + eps
```

### 항 1 — 노드별 energy score

```
ES_node  =  (1/N) Σ_i [ (1/M) Σ_m d_i^(m)  −  c(M,α) Σ_{m<n} e_i^(mn) ]  /  s
```

**하는 일**: 각 노드의 3차원 주변분포를 보정한다. 노드마다 독립적으로 strictly proper.

**스텝당 제약 수**: `N × O(M²)` ≈ 50,000 × 6 = **300,000개**
→ 이 항이 학습의 **일꾼**이다. 실제 운영 기상 모델(ECMWF AIFS-CRPS)의 학습 loss가
격자점별 CRPS인 것과 같은 이유다.

**gradient (노드 i, 멤버 m)**:

```
정확도 쪽:  + (1/M) · (y_hat_i^(m) − y_i) / d_i^(m)             ← 자기 노드 오차 방향
퍼짐   쪽:  − c · Σ_n (y_hat_i^(m) − y_hat_i^(n)) / e_i^(mn)    ← 자기 노드에서 멀어지는 방향
```

분모가 전부 **노드별**이다. 어느 노드에서 폭이 부족한지 정확히 식별한다.

**못 보는 것**: 노드 **사이**의 상관. 모든 노드의 주변분포가 완벽하지만 서로 독립인
샘플(= 공간적 백색잡음)이 이 항에서 만점을 받는다. **요구 ①(사실성)에 대해 무력하다.**

### 항 2 — 필드 전체 energy score

```
ES_graph  =  [ (1/M) Σ_m D^(m)  −  c(M,α) Σ_{m<n} E^(mn) ]  /  s
```

**하는 일**: 필드 전체를 벡터 하나로 보고 **결합분포**를 채점한다. 전체 진폭·모드 형상에
민감. 항 1이 못 보는 노드 간 상관에 압력을 준다.

**스텝당 제약 수**: `O(M²)` = **6개**
→ 150,000차원을 6개 숫자로 제약한다. **식별력이 거의 없다.**

**gradient (노드 i, 멤버 m)**:

```
정확도 쪽:  + (1/M) · (y_hat_i^(m) − y_i) / (N · D^(m))
                       └─ 노드별 ─┘         └─ 전역 ─┘
```

분자는 노드별이지만 분모가 전역이다. → **재구성은 노드별로 정상 작동**하지만
(방향이 자기 오차에 비례), **퍼짐은 총량만 맞추면 되므로 노드별 식별력이 없다.**

### 두 항이 필요한 이유 (그리고 왜 딱 두 개인가)

| | 제약 수 | 요구 ① 사실성 | 요구 ② 보정 |
|---|---|---|---|
| `ES_node` 단독 | 300,000 | ✗ 공간적 백색잡음 허용 | ✓ 주변분포 |
| `ES_graph` 단독 | 6 | △ 압력은 있으나 정보 부족 | △ 큰 스케일만 |
| **합** | 300,006 | △ | ✓ |

- 항 1은 **정보량**을 공급한다 (학습이 실제로 진행되게 함)
- 항 2는 항 1의 **사각지대**(공간 상관 = 사실성)를 덮는다
- 중간 스케일(클러스터 pooling)은 두 항 사이의 보간이므로 **필수가 아니다.**
  진단에서 특정 스케일의 결함이 관측될 때만 추가한다.

### 총합

```
L  =  w_node · ES_node  +  w_graph · ES_graph

시작값:  w_node = 1.0,  w_graph = 0.3,  M = 3,  alpha = 0.95
```

### `alpha` 가 정확도/퍼짐 손잡이다

```
alpha = 1.00   완전 fair. 퍼짐에 후함
alpha = 0.95   표준 (CRPS-LAM 채택값)
alpha = 0.80   정확도 쪽으로 기울임 (= "recon 가중치를 올린" 효과)
```

`L = ES + lambda·MSE(앙상블 평균, y)` 형태로 섞으면 **안 된다.** 앙상블 평균에 상을 주면
멤버들이 서로 붙어 under-dispersion 이 생기고 proper 성질이 깨진다. `alpha` 가 이것의
수학적으로 올바른 대체물이다.

### 필수 구현 세부

1. **eps 평활화**: `sqrt(·)` 는 0에서 미분 불가. `+eps²` 없이 돌리면 잘 맞출수록 터진다.
2. **지수 = 1 고정**: 거리 지수 `‖·‖^beta` 에서 `beta<1` 은 gradient 발산 → 즉시 붕괴.
3. **`s` 는 detach**: 그래프별 정규화는 가중치이지 목적함수의 일부가 아니다.
   양의 상수배는 proper 성질을 보존한다.
4. **`M ≥ 2`**: `M=1` 이면 퍼짐항이 존재하지 않아 z를 무시하도록 학습된다 (함정).
5. **입력 노이즈는 M-루프 밖에서 1회**: 제자리 수정이면 M번 누적된다.

### 반드시 로깅할 것

```
epoch N | acc 0.68 | spread 0.27 | zsens 0.31 | joint 0.12
          ↑           ↑            ↑            ↑
    정확도항      퍼짐항      z 민감도      ES_graph
                              std_m(y_hat)/std(y)
```

- `spread → 0` 또는 `zsens → 0`: z가 무시되는 중 (붕괴)
- `acc` 가 결정론적 baseline 대비 크게 나쁨: `alpha` 를 낮춘다
- `joint` 만 나쁨: 공간 상관 문제 → 중간 스케일 항 추가 검토

## 6. 설계 C — 측정이 애매할 때 (가장 현실적인 시나리오)

측정 3.1 이 "평균 필드는 국소 구조가 있는데, **샘플 간 변동**은 매끄럽다" 로 나올 가능성이
가장 높다. 물리적으로 그렇다: 평균 형상은 부품 배치/두께 분포 같은 국소 요인이 만들고,
**샘플 간 차이**는 전역 warpage 모드가 지배한다.

이 경우가 정확히 §4의 설계 B 이다 — `mu_θ` 가 전 해상도 국소 구조를 담당하고,
`Phi·a` 는 매끄러운 변동만 담당한다.

**판정 기준**: 잔차 `r_s = y_s − mu_θ(g_s)` 에 대해 다항식 R² 를 다시 잰다.
필드 전체보다 잔차 쪽 R² 가 높으면 설계 B/C 가 맞다.
